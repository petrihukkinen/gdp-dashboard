# 08_OPERATING_MODEL

Full Gate 4 governance structure, Asset Performance Office design, and RACI are not started
— see protocol Section 11. AMOR 2020's own governance/working-group structure (11 working
groups, slide 34) is analyzed as raw input in `02_AMOR_ORIGINAL/AMOR_2020_ANALYSIS.md` ("ten
ideas worth carrying into AMOR 2030," #9).

**One piece is built ahead of Gate 4:** `VALUE_VALIDATION_BOARD_MVP.md` (Cycle 3) — the
minimum viable governance needed to operate the Gate 2 attribution architecture
(`07_KPI_ATTRIBUTION/`). This is deliberately narrow (membership, voting, cadence,
escalation for value-claim adjudication only) and does not attempt the full Asset
Performance Office/RACI design, which stays Gate 4 scope.
